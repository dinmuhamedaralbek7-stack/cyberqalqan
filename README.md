CyberQalqan SMS, WhatsApp, Telegram хабарламаларындағы сілтемелерді **ашпай тұрып** тексереді. Қауіпті болса — «БАСПАҢЫЗ!» дабылы, 102 батырмасы және сенімді туысқа бір басумен хабарлау («Отбасылық қалқан»).

## Мүмкіндіктер
- **Үш қабатты талдау:** эвристика (телефонда, интернетсіз) → домен сенімі (жасы, рейтингі, HTTPS, OpenPhish) → ChatGPT (тек серверде).
- **Шұғыл дабыл:** толық экранды қызыл ескерту, дыбыс пен діріл, 102.
- **Отбасылық қалқан:** туыс шақыру сілтемесі мен 6 таңбалы кодпен растайды; ескертуге сілтеме, SMS-код, карта нөмірі қосылмайды; автоматты жіберу жоқ.
- **Android:** сілтемені басқанда тексеру (әдепкі браузер рөлі), экрандағы домалақ батырма, SMS жанындағы «Тексеру» батырмасы. Lite және Толық нұсқа.
- **iPhone:** Safari арқылы басты экранға қосылатын веб-қосымша.
- **Қауіпсіздік:** 2FA (биометрия + PIN), Android Keystore AES-256-GCM, CSP, rate limit, API кілттері тек серверде.

## Құрылымы
| Папка | Не бар |
|---|---|
| `web/` | Сайт / PWA (`index.html`), туыстың растау беті (`family.html`), құпиялылық саясаты |
| `api/` | Vercel serverless: `trust.js` (домен сенімі), `ai.js` (ChatGPT) |
| `android/` | Kotlin қосымшасы (`full` / `lite` нұсқалары) |
| `tools/` | `csp.py` (JS өзгерсе — міндетті түрде іске қосу), иконка генераторы |
| `media/` | Презентация мен орнату видеосы |
| `build.sh`, `vercel.json` | Vercel-де сайт + APK жинау |

## Іске қосу (Vercel)
1. Бүкіл папканы Vercel-ге жариялаңыз (`web` емес!). Framework Preset: Other.
2. Жинау ~10 мин: Android SDK жүктеліп, `CyberQalqan.apk` және `CyberQalqan-Lite.apk` жиналады.
3. Тексеру: `https://<сайт>.vercel.app/apk.json` → `{"ok":true,...}`.
4. ChatGPT (міндетті емес): Settings → Environment Variables → `OPENAI_API_KEY`.

## 🔐 Қолтаңба кілті
APK-ға қол қоятын кілт (`android/app/cq-release.keystore`) мен `android/app/keystore.properties` **репозиторийде жоқ** (`.gitignore`). Оларды қауіпсіз жерде сақтаңыз. Кілтсіз жиналған APK debug кілтімен қол қойылады және бұрын орнатылған CyberQalqan-ды жаңарта алмайды.
